MSMエマグラム

気象庁メソモデル(MSM)の予報を Open-Meteo API から取得して描画します。地点の標高より下の気圧面を除いて地上点を加え、逆転層を判定します。

同じ地点名で保存すると上書きされます。登録した地点はこのブラウザに保存されます。MSMの範囲は北緯22.4〜47.6°、東経120〜150°です。

—
接地逆転あり 上空逆転あり(300hPaより下) 逆転層なし

MSMの気圧面は 1000〜900hPa で25hPa間隔、それより上は50〜100hPa間隔のため、薄い逆転層は捉えられないことがあります。湿度は300hPaまでしか提供されないため、それより上は露点を描きません。
「MSM地上値」は Open-Meteo が地点標高に合わせて補正した2m気温・地上気圧を使います。気象データ: 気象庁 MSM / Open-Meteo.com (CC BY 4.0)
